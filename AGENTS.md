# Organization profile repository

Holds the BehindTheMusicTree organization profile (`profile/README.md`), shared assets (`assets/`), funding config and the default pull request template (`.github/pull_request_template.md`).

- Keep every heading of the PR template; sections that do not apply are written `N/A`.
- Profile and template changes are visible org-wide: keep them accurate and consistent with `github-config`.
- No build or tests; verify rendered markdown and relative asset links.
